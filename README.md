# 基于 SpringBoot + Vue 的旅游住宿小程序 (Travel Accommodation Mini Program)

民宿预定 · 景点浏览 · 旅游攻略 · 论坛社区 · 订单管理 · 订单评价 · 数据统计

本项目是一套面向旅游目的地、景区民宿及旅行爱好者的旅游住宿小程序，采用前后端分离架构，覆盖管理员与用户两类角色。系统围绕"前端导航管理、景点发布、旅游攻略、民宿预定、房间管理、订单管理、订单评价、论坛社区"等核心业务设计，支持用户浏览景点与攻略、预定民宿房间、发布论坛帖子、参与评价互动，管理员负责平台前端导航配置、景点与攻略内容发布、民宿与房间管理、订单统计与论坛管理，实现从旅游信息展示、民宿预定、订单处理到社区互动的全流程数字化管理，适用于景区民宿平台、乡村旅游服务平台、旅游目的地信息小程序及民宿预订系统。

## 核心特性

- **景点发布与管理**：管理员发布景点信息，包括景点名称、位置、图片、介绍、开放时间、门票价格、经纬度坐标，支持增删改查与地图定位展示。
- **旅游攻略发布**：管理员发布旅游攻略内容，包括攻略标题、目的地、行程路线、交通指南、美食推荐、图文详情，支持增删改查与分类管理。
- **民宿与房间管理**：管理员管理民宿信息（名称、地址、设施、图片、评分）与房间信息（房型、床型、价格、库存、设施），支持房间状态管理（可用/已预订/清洁中）。
- **民宿预定**：用户选择入住/离店日期与房型，系统实时校验房态与价格，提交预定订单并完成在线支付。
- **订单管理与统计**：管理员查看所有订单列表与订单状态（待支付/已支付/已入住/已完成/已取消），支持订单统计（订单量、入住率、营收趋势、热门民宿排行），数据可视化展示。
- **订单评价**：用户完成入住后可对民宿与服务进行评分与文字评价，评价信息供其他用户参考，管理员可查看与管理评价内容。
- **论坛社区**：用户可发布旅游分享帖子、查看帖子详情、评论回复，形成旅游交流社区，管理员可管理帖子与回复内容。

## 功能模块概览

## 管理员端

管理员负责平台整体运营、内容发布、民宿与房间管理、订单统计与论坛管理：

### 前端导航管理

- **导航展示管理**：动态配置小程序首页导航菜单，包括导航名称、图标、跳转路径、排序序号、显示状态（显示/隐藏），支持添加、修改、删除、查询导航项，灵活调整前端页面展示结构，无需重新发布小程序。

### 内容发布与管理

- **景点发布**：发布景点信息，包括景点名称、所属地区、位置描述、经纬度坐标、景点图片、详细介绍、开放时间、门票价格、推荐等级，支持增删改查与上下架管理。
- **旅游攻略发布**：发布旅游攻略内容，包括攻略标题、目的地、行程天数、交通指南、住宿推荐、美食推荐、图文详情、发布作者，支持增删改查与分类标签管理。

### 民宿与房间管理

- **民宿管理**：管理民宿信息，包括民宿名称、地址、联系电话、设施清单（WiFi/停车场/早餐等）、民宿图片、评分、营业状态，支持增删改查与上下架。
- **房间管理**：管理民宿房间信息，包括房型名称（单人间/双人间/家庭房等）、床型、面积、可住人数、房间价格、房间库存、房间设施、房间图片，支持增删改查与房态管理（可用/已预订/清洁中/维修中）。

### 订单管理与统计

- **订单管理**：查看所有民宿预定订单列表，包括订单号、下单用户、民宿名称、房型、入住/离店日期、订单金额、订单状态（待支付/已支付/已入住/已完成/已取消），支持按状态、时间、民宿筛选与订单处理。
- **订单统计**：统计平台核心订单数据，包括订单总量、入住率、营收金额、热门民宿排行、用户地域分布等，支持按时间范围（日/周/月）筛选，数据以图表形式可视化展示。
- **订单评价**：查看用户对民宿的评分与评价内容，支持评价审核与异常评价处理，统计民宿平均评分与服务满意度。

### 论坛管理

- **论坛帖子管理**：管理用户发布的论坛帖子，包括帖子标题、内容、发布者、发布时间、评论数、点赞数，支持帖子审核、置顶与违规帖子删除。
- **论坛回复管理**：查看论坛帖子的评论回复内容，支持回复审核与违规评论删除。

## 用户端

用户面向平台注册用户，提供景点浏览、攻略查看、民宿预定、论坛互动与订单管理功能：

### 首页与导航

- **前端导航展示**：首页展示管理员配置的导航菜单，用户点击导航图标跳转至对应页面（景点、攻略、民宿预定、论坛等），导航布局灵活可配置。

### 景点与攻略

- **景点浏览**：浏览景点列表，按地区、类型等条件筛选，查看景点详情（图片、介绍、开放时间、门票价格、地图位置），支持收藏景点。
- **旅游攻略查看**：浏览旅游攻略列表，按目的地、行程天数等条件筛选，查看攻略详情（行程路线、交通指南、美食推荐、图文内容），支持点赞与收藏攻略。

### 民宿预定

- **民宿浏览**：浏览民宿列表，按地区、价格、评分、设施等条件筛选，查看民宿详情（图片、设施、评分、用户评价、周边景点）。
- **房间选择与预定**：选择入住/离店日期，查看可用房型与实时房态，选择房型与数量，系统自动计算订单金额，确认订单信息后提交预定。
- **在线支付**：订单提交后通过微信支付或支付宝完成在线支付，支付成功后订单状态更新为已支付，生成入住凭证。

### 订单与评价

- **我的订单**：查看个人预定订单列表与订单状态（待支付/已支付/已入住/已完成/已取消），支持取消订单（入住前）与查看订单详情。
- **订单评价**：完成入住后可对民宿与服务进行评分（1-5星）与文字评价，支持上传评价图片，评价信息展示在民宿详情页供其他用户参考。

### 论坛社区

- **论坛帖子查看**：浏览论坛帖子列表，查看帖子详情，参与旅游交流与经验分享。
- **消息回复**：发布论坛帖子与评论回复，接收他人对自己帖子的回复通知，查看回复消息并参与互动。
